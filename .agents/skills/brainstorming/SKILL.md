# Brainstorming

Facilitates structured ideation and exploration before implementation.

## Purpose

Generate solution directions, identify trade-offs, and surface unknowns before committing to implementation.

## When to Use

- Before creating PRDs or technical specs
- When requirements are ambiguous
- For exploring multiple solution approaches

## Process

1. Define the problem space and constraints
2. Generate 3-5 candidate solution directions
3. Analyze trade-offs for each direction
4. Identify open questions and unknowns
5. Recommend a path forward with rationale

## Output

- Candidate solutions with pros/cons
- Key decisions to confirm
- Open questions for stakeholders
- Recommended approach
