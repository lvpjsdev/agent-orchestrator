# Coding Agent

Core skill for autonomous code implementation and modification.

## Purpose

Enable agents to write, modify, and refactor code following project conventions.

## Capabilities

- Read and understand existing codebase
- Write new features following patterns
- Refactor for clarity and maintainability
- Fix bugs with minimal scope creep
- Generate tests for implemented code

## Constraints

- Follow existing code patterns
- Respect project conventions in AGENTS.md
- Do not introduce new dependencies without approval
- Keep changes minimal and focused

## Process

1. Understand task from PRD
2. Locate relevant existing code
3. Implement following patterns
4. Write/update tests
5. Verify with lint/typecheck
