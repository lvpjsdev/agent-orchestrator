# Web Search

Search the web for current information and documentation.

## Purpose

Retrieve up-to-date information not present in training data.

## Capabilities

- Search for documentation and tutorials
- Find current library versions
- Look up error messages and solutions
- Research best practices

## Process

1. Formulate search query
2. Execute search via API
3. Extract relevant information
4. Cite sources in response

## Guidelines

- Prefer official documentation
- Verify information from multiple sources
- Note date of information
- Be specific in queries

## Use Cases

- "What's new in React 19"
- "How to configure Tailwind v4"
- "Error: [specific error message]"
