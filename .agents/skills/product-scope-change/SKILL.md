# Product Scope Change

⚠️ **FORBIDDEN** in devops stage - Scope changes require manager approval.

## Why Forbidden

DevOps operations should not modify product scope. Scope changes must go through proper channels:

1. Manager stage review
2. PRD update
3. Stakeholder approval

## Allowed Actions

- Infrastructure changes
- CI/CD pipeline modifications
- Deployment configurations
- Performance optimizations

## Not Allowed

- Adding new features
- Changing requirements
- Modifying acceptance criteria
- Expanding project scope

## Remediation

If scope change is needed, create a task with `@human` tag and escalate to manager stage.
